# Castaway Beacon (Defold)

Touch-first island-survival game — Defold implementation. See
[docs/HANDOFF.md](docs/HANDOFF.md) for full design, status, and the Defold-format
pitfalls discovered while building this.

## Quick start

```bash
# build (headless, JDK ≤21 required; bob 1.11.0 is cached in .defold-cache/)
java -jar .defold-cache/bob.jar --platform x86_64-linux --archive build --variant headless

# verify the gameplay loop headlessly (scripted autoplayer)
CB_AUTOPLAY=1 build/headless/unnamed/unnamed.x86_64
```

Art assets are generated by the sibling Phaser repo's `scripts/generate-art.py` and
split into per-frame PNGs under `assets/images/`.
