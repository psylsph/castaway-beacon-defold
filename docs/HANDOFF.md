# Castaway Beacon — Design & Status

Touch-first island-survival game inspired by "Last Beacon: Survival" fake-ad gameplay.
Lone castaway collects ocean debris, expands a raft, builds huts, fishes, digs to grow
the island, and rescues survivors through a storm → shipwreck → arrival story arc.

**Two implementations exist in this GitHub org:**

| Repo | Engine | Status |
|---|---|---|
| `castaway-beacon` | Phaser 3.90 + TypeScript, PWA | Playable vertical slice + narrative, deployed, 52/52 tests |
| `castaway-beacon-defold` | Defold 1.11 (Lua), headless-built | Boot + full gameplay loop verified headless; HUD/touch/polish pending |

## Design

### Core loop (per ~2-minute in-game day)
1. **Collect** driftwood from an 8-point shoreline ring (3 active nodes max, 6 spawn per day)
2. **Build** — escalating blueprints, 1 build/day each:
   - Raft platform: 5 wood (4 shore slots)
   - Hut: 10 wood (3 inner slots) — beds raise settlement capacity
   - Water collector: 8 wood
3. **Fish** at the east shallows: walk there, 2.5s work, +2 food
4. **Dig** at the west shore: 4 trips expand the island (land level +1, walkable ellipse grows)
5. **Story beats fire once each** (state-gated, deduped):
   - Night of day 2+: "The storm"
   - Day 3+, 5+ wood collected: "Wreckage on the tide"
   - First hut: "A roof of your own"
   - Land level 1+: "New ground"
6. **Arrivals** (gated on day AND hut count): Mira (day 4+, needs 2 huts), Tomas (day 6+, needs 3 huts). Population HUD updates.

### World model (single source of truth)
- Walkable sandbar: ellipse centre (240, 356), radii 138×63, walk limit 0.82 of radius
- Movement: 60 px/s, arrival-based actions (walk → `working` → resolve → `idle`)
- Day: 120s; night tint at the 60s midpoint
- Actor: starts (248, 380); one pending action at a time
- Draw order: depth = world y (y-sort), sprites at 2× integer scale

### Art
- All assets generated by `scripts/generate-art.py` (Python + Pillow, seeded, deterministic)
- 18-frame atlas: castaway 3-direction idle/walk, campfire (2-frame), palms, driftwood, hut ×2, raft, tent
- 480×640 pre-rendered island background (same ellipse constants as the physics)
- No licensed binaries; regenerate by editing the script
- Style target: the ad reference (thatched huts, straw-hat farmer, campfire, fences)

### Distribution intent (Poker/Poki best practices applied)
- Load < 20MB (Phaser bundle ≈ 1.3MB; Defold builds are smaller still)
- Gameplay within seconds, touch-first portrait, continuous simple loop
- PWA install (Phaser) and native export paths (Defold)

## Repo 1: `castaway-beacon` (Phaser)

- **Stack**: Vite vanilla-TS, Phaser 3.90, vitest, eslint, vite-plugin-pwa
- **Run**: `docker compose build && docker compose up -d` → `http://0.0.0.0:8081` (`/health` → `ok`)
- **Dev**: `npm install && npm run dev -- --host 0.0.0.0`
- **Checks**: `npm run check` (lint + tsc + vitest + PWA build) — all green at last commit
- **Modules** (`src/game/`): `world.ts`, `types.ts`, `simulation.ts`, `day-content.ts`,
  `spawn-director.ts`, `buildings.ts`, `actor-movement.ts`, `day-cycle.ts`, `driftwood.ts`,
  `survival.ts`, `survival-actions.ts`, `story.ts`, `island-scene.ts`
- **Known bug**: actor can get stuck in `working` mode after a dig/work completes at a spot
  that is also an action target; subsequent commands report "Already busy". Reproduced
  in-engine; fix = reset `pendingWork`/`pendingAction` bookkeeping when `completeWork` fires.
- **Verified in-engine**: collect ×10 → hut → storm + wreck text on day-2 night → fish +2
  food → 4 digs → land grows. Day-1 build cap enforced (2nd raft refused).

## Repo 2: `castaway-beacon-defold` (Defold)

- **Stack**: Defold 1.11.0, built headless with `bob.jar` (in `.defold-cache/`, needs JDK ≤21 —
  bob 1.12+ requires JDK 25; `openjdk-25-jre-headless` is in apt but needs sudo password)
- **Build**: `java -jar .defold-cache/bob.jar --platform x86_64-linux --archive build --variant headless`
- **Run (headless verify)**: `CB_AUTOPLAY=1 build/headless/unnamed/unnamed.x86_64`
- **Structure**: `game/{world,survival,build}.lua` (pure logic ports), `main/island.script`
  (scene driver), `assets/images/` (split frames + `images.atlas`), `main/main.collection`
- **Defold format traps learned** (save the next AI from these):
  - `.collection` referenced GOs use `instances { id, prototype: "/path/x.go" }`;
    inline GOs use `embedded_instances { id, data: "..." }` where `data` is adjacent
    quoted string fragments (protobuf TextFormat concatenation). `component:` inside a
    collection instance is INVALID (silently dropped or build error).
  - InstanceDesc fields: id, prototype, children, position, rotation, scale3 — no `data`
  - EmbeddedInstanceDesc fields: id, data, children, position, rotation, scale3
  - Input: `TOUCH` enum does not exist in 1.11 input bindings; use `MOUSE_BUTTON_1` → "touch"
  - Labels use `/builtins/fonts/vera_mo_bd.ttf` + `/builtins/fonts/font.material`
    (NOT `system_font.font` which doesn't exist in headless builds)
  - **Headless engine aborts natively (no Lua error) on nil-module calls** — a `return M`
    placed mid-module (above appended functions) makes require'd fields nil. Crash without
    any script error message. Always `return M` last.
  - The label component crashes the headless engine at first render (no font rasteriser) —
    HUD must use gui or be deferred to non-headless builds
- **Autoplay verification harness**: `CB_AUTOPLAY=1` drives a scripted playthrough
  (collect → hut → fish → dig ×4) and prints ANNOUNCE/STATUS lines. Verified: driftwood
  economy, first catch, dig expansion + "New ground" beat, storm + wreck beats on day 2,
  day rollover with node respawn.

## Decisions & constraints

- **All servers bind 0.0.0.0** (user requirement)
- **Every advertised transformation must happen through real player actions** (no fake-ad gameplay)
- **Deterministic assets** — generated pixel art, no licensed content
- **TDD on the Phaser repo**: red → green, `npm run check` before every commit
- **Roblox Studio + MCP was evaluated and rejected** (Studio needs Windows/macOS; user is Linux-only)
- **Defold chosen for the port** for: native exports, Linux-native tooling, MCP/agent
  build pipeline (bob.jar + dmengine_headless), Poki path, tiny web builds
- Economy constants: FISH_YIELD 2, DIGS_PER_EXPANSION 4, DAY 120s, hut 10w, raft 5w

   SCHEMA_VERSION 1 already)
6. **Playwright smoke tests** (Phaser), headless assertions (Defold)
7. Consider Poki submission once the Defold HTML5 build is playable
